## Project Overview

For Unikraft to be a viable alternative to Docker in production, it needs to run the software 
people actually deploy. Right now the catalog covers the basics  Nginx, Redis, SQLite etc 
but there are major gaps. You can’t run a DNS server, a message broker, a time sync 
daemon, or a Git host as a unikernel without doing the porting work yourself. That’s a 
problem because engineers evaluating unikraft for their stack will look at the catalog and if 
their workload isn’t there, they move on. 

This project fills those gaps!

## Progress
- **dnsmasq** — DNS forwarder/cache over UDP+TCP with DNSSEC. Also updated
  `lib-nettle` to 4.0 ( now its arch independent ) for  crypto, and wired  netlink
  interface discovery. Builds on x86_64 and arm64 , with CI.
- **lighttpd** — lightweight web server .


## Next Steps
- Port Chrony, and keep filling catalog gaps.
- Fix the arm clock which is hindering dnssec on the arm build.
